# Assignment #4: Forms and Validation

## Project Overview
This project demonstrates basic HTML forms, HTML5 built-in validation, Bootstrap form styling, Bootstrap validation feedback, and a responsive registration form.

## Files
- `index.html` — all assignment tasks and form markup.
- `style.css` — custom responsive styling.
- `script.js` — validation feedback and demo submission behavior.
- `REPORT.docx` — report template with task explanations and screenshot placeholders.

## How to Run
1. Extract the project ZIP file.
2. Open `index.html` in a modern web browser.
3. An internet connection is needed to load Bootstrap 5.3 from its CDN.
4. Test each form with both invalid and valid input.

## Tasks Implemented
- **Task 0:** Contact form with name, email, message, labels, and submit button.
- **Task 1:** HTML5 validation attributes including `required`, `type`, `minlength`, and `maxlength`.
- **Task 2:** Bootstrap form classes, grid layout, placeholders, and helper text.
- **Task 3:** Bootstrap `is-valid` / `is-invalid` behavior through `needs-validation`, `was-validated`, and feedback classes.
- **Task 4:** Responsive registration form with first and last name, email, password confirmation, gender radio buttons, hobby checkboxes, country dropdown, submit and reset buttons.

## Important Note
This is a front-end demonstration. Forms validate input in the browser but do not send information to a server or create real user accounts.
